# JrDesign — Portafolio de Johan Rivera

Portafolio personal como Desarrollador Frontend, construido desde cero con HTML, CSS y JavaScript puro (sin frameworks).

## 🔗 Demo en vivo
[johanrf.github.io/-Johan-s-Portfolio](https://johanrf.github.io/-Johan-s-Portfolio/)

## 📋 Qué incluye
- Sección de proyectos con demos en vivo y enlaces a código
- Sección de habilidades organizada por nivel (base sólida / en progreso / herramientas de IA)
- Modo claro y oscuro con toggle persistente
- Diseño responsive, mobile-first

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 (variables CSS, Flexbox, Grid)
- JavaScript (ES6+) para el toggle de tema

## 🚀 Cómo correrlo localmente
\`\`\`bash
git clone https://github.com/JohanRF/-Johan-s-Portfolio.git
cd -Johan-s-Portfolio
# abrir index.html directamente en el navegador
\`\`\`

## 🧠 Qué aprendí
Construir un sistema de theming completo con variables CSS (`--bg`, `--accent`, `--text`, etc.) que cambian dinámicamente según el atributo `data-theme`, sin depender de ninguna librería.
